# Boss Moments Like 朋友圈点赞学

领导发了一条朋友圈。赞还是不赞？评论还是不评论？这个技能给一个可执行的判断，而不是「看情况」。

A WeChat Moments post from someone with power over you is a small, low-stakes social test that people get wrong in both directions — ignoring reads as aloof, over-engaging reads as trying too hard. The right move depends almost entirely on what kind of post it is.

## 语言 Language

用用户提问的语言解释，**小标题也一起翻译**，不要一半中文一半英文。但**评论/话术保持中文**——那是要发到朋友圈里的，翻成英文就无法使用。

Explain in the user's language, including the section headings, but keep the comment drafts in Chinese: they are posted to WeChat Moments and lose their meaning if translated.

## 第一步：判断这条是什么性质

先分类，再决定动作。分类错了，后面全错。

| 类型 | 长什么样 | 社交含义 |
|---|---|---|
| **工作汇报** Work report | 会议照片、签约、项目上线、出差定位 | 希望你看到 —— 这是发给「观众」的 |
| **生活炫耀** Life flex | 旅行、美食、孩子、新东西 | 展示型，**不需要观众配合** |
| **价值观宣示** Values | 鸡汤、行业感悟、读书笔记、长篇感慨 | 有些是自我表达，有些是**在考察认同** |
| **求助暗示** Indirect ask | 「最近有点累」「有没有熟悉 X 的朋友」 | **最危险的一类**，可能是在等特定的人回应 |
| **钓鱼** Bait | 模糊的情绪、意味深长的短句 | 试探谁在关注 |
| **丧事 / 家事** Grief | 生病、去世、家庭变故 | **只能沉默**，任何互动都是失礼 |

判断方法：看配图（官方图 = 汇报；生活照 = 炫耀）、看长度（长文 = 宣示）、看有没有 @ 或定位。

## 第二步：决策矩阵

| 类型 | 点赞 | 评论 | 说明 |
|---|---|---|---|
| 工作汇报 | ✅ 可以 | ⚠️ 少评 | 点赞是安全的，评论容易被当成表态 |
| 生活炫耀 | ✅ 可以 | ❌ 不评 | 点赞即可，评论容易显得刻意 |
| 价值观宣示 | ⚠️ 看关系 | ⚠️ 谨慎 | 点赞即「我同意」，先想清楚是否愿意被这么理解 |
| 求助暗示 | ❌ 不赞 | ❌ 不评 | 点赞等于说「我在但我不帮」，比沉默更差 |
| 钓鱼 | ❌ 不赞 | ❌ 不评 | 不参与是对的答案 |
| 丧事 / 家事 | ❌ **绝对不赞** | ❌ 绝对不评 | 私信或当面，公开场合一律不动 |

**通用原则：不确定就不要动。** 点赞的收益很小，点错的成本很大。

## 第三步：评论区三档

只在**工作汇报**或者**关系足够近**的情况下才用。

### 档位一：最低限度（几乎零风险）
```
👍
辛苦了
```
一个表情就是完整回复。不要加字。

### 档位二：安全（认可付出，不做评价）
```
这个项目确实不容易，恭喜
看着就累，注意身体
```
结构：**认可努力 → 不评价结果**。

### 档位三：建立关系（只有真的熟才用）
```
这块当时卡了很久吧？能推下来厉害
下次有机会想请教一下
```
结构：**具体的、只有内行才会问的细节** —— 这才显得是真在意，不是客套。

## 绝对不能做的

- **领导发丧事/家事，去点赞** —— 这是这类场景里最常见的致命错误
- **在评论区开玩笑** —— 文字没有语气，玩笑会被读成别的
- **评论里提工作** —— 会被当成借机汇报或施压
- **同一个领导连续多条都评论** —— 从「有礼貌」变成「刻意」
- **评论其他同事的评论** —— 把一对一的互动变成公开表态

## 输出格式

```markdown
**类型判断：** <类型> —— <依据：配图/长度/措辞>
**动作建议：** 点赞 / 不点赞 / 评论 / 完全不互动
**理由：** <一句话>

**如果要评论，三档可选：**
- 最低限度：`...`
- 安全：`...`
- 建立关系：`...`

**风险提示：** <这条互动可能被怎么解读>
```

## 规则

- **默认答案是「不互动」。** 只有当有明确理由时才建议动作。
- **丧事、家事、政治、健康问题 → 一律不互动**，不讨论，不给替代方案。
- **区分「发给你看的」和「发给所有人看的」。** 前者要回应，后者可以不回应。
- 如果用户和这个人的关系本身有问题（正在被穿小鞋、正在谈离职），建议**一律不互动**，任何互动都可能被解读成信号。
