# Parent Group Survival 家长群生存

有些群你退不了：孩子还在人家班上，房子还在这儿，亲戚还在一块吃饭。这个技能处理的就是**不能退的群**——目标不是赢，是体面地待着。

Some groups you cannot leave. The goal is not to win the conversation; it is to stay in it without losing face and without committing to things you cannot deliver.

## 语言 Language

用用户提问的语言解释。但**回复话术本身必须是中文**——这是要直接粘进微信群发出去的，翻成英文就废了。即使用户用英文提问，三档回复也保持中文。

Explain in the user's language, but keep the reply drafts in Chinese: they are meant to be pasted into the group chat, and translating them makes them unusable. Chinese source phrases should be quoted, not paraphrased away.

## 第一步：先判断这是什么群

同一个群里，不同消息的性质完全不同。先看群的整体气质：

| 群型 | 特征 | 你该怎么待 |
|---|---|---|
| **通知群** Announcement | 只有老师/物业/组织者发，其他人基本不说话 | 只回「收到」，不多话 |
| **表演群** Performance | 家长互相晒、互捧，消息刷屏 | 选择性参与，别缺席太久 |
| **拉票群** Vote-farming | 频繁「帮孩子投个票」 | 投票不花钱就投，别开先例 |
| **踩雷群** Landmine | 什么话题都可能得罪人，有隐性派系 | 只回应事实，不表态 |
| **交易群** Transaction | 团购、二手、拼车 | 按交易规则来，不掺和人情 |

判断依据：最近 20 条消息里，非组织者占比、是否有互捧结构、是否有人被公开 @ 逼表态。

## 第二步：判断要不要回

**大多数消息不需要回。** 先过这一关，再谈怎么回。

必须回的：
- 被直接 @ 且点名提问
- 老师/物业/组织者在征集信息（接龙、报名、交材料）
- 已经在公开场合被追问第二次

**可以不回**：
- 别人晒成绩、晒旅游、晒礼物
- 群里的观点争论（你不是当事人）
- 「大家觉得呢」这种开放式提问

**绝对不要回**：
- 深夜的情绪化发言
- 关于老师/物业的负面评价（哪怕是附和）
- 任何可以被截图转发的立场表态

## 第三步：三档回复

按「你愿意付出多少」选，不要一上来就用最高档——**档位用高了以后降不下来**。

### 档位一：最低限度 Minimum
只表示「我看到了」，不提供任何额外信息。

```
收到 ✅
好的，谢谢老师
[一个表情]
```

### 档位二：安全 Safe
表示看到了 + 一点点内容，但**不做任何承诺**。

```
收到，我今晚确认一下再回复您
了解，我们家按通知准备
好的，有需要随时说
```

关键：把动作推迟到「确认一下」，永远不当场承诺。

### 档位三：高情商 High-EQ
给对方台阶，同时守住自己的边界。**说得好听的拒绝，仍然是拒绝。**

```
这次可能跟不上大家了，孩子这两天在准备比赛，回头我补上 🙏
谢谢老师提醒，我们家照做，您辛苦了
这个我们不太擅长，就不占名额了，祝大家玩得开心
```

结构是：**先认可对方的付出 → 再说明自己的情况 → 给一个不负担的祝福/承诺**。

## 危机处理

**发错群了**
1. 立刻撤回（2 分钟内）
2. 超过 2 分钟：发一句轻描淡写的话盖过去，不要长篇解释
3. 绝对不要再发「不好意思发错了」——这会把注意力吸引过来

**手滑点了个赞**
不解释。撤回点赞反而更显眼。等它沉下去。

**被人 @ 逼着表态**
不站队，只描述事实：「我这边了解到的是 X，具体还得看安排。」

**说错话了**
私下找相关的人补一句，公开场合不再提。公开道歉会放大。

## 输出格式

```markdown
**群型判断：** <类型> —— <依据>
**要不要回：** 必须回 / 可以不回 / 绝对不要回 —— <理由>

**潜台词：** <这句话表面说什么，实际在说什么>

**回复建议**
- 最低限度：`...`
- 安全：`...`
- 高情商：`...`

**风险提示：** <这条回复可能带来的副作用>
```

## 规则

- **先判断要不要回，再决定怎么回。** 大部分人问「怎么回」的时候，正确答案是「不用回」。
- **档位从严。** 第一次就用高情商回复，之后就再也用不了「收到」了。
- **不写阴阳怪气的话。** 群里说的话会被截图，讽刺的成本远高于收益。
- **不替用户做价值判断。** 如果涉及家庭矛盾、教育理念，只给沟通建议，不站队。
- 如果用户描述的是**已经激化的冲突**（被围攻、被公开指责），建议私聊或转线下，不要在群里解决。
